# 📡 TopGit Radar - Báo Cáo Tự Động Hàng Ngày

> Dự án tự động quét TopGit.dev và GitHub.com, phân tích và dịch tóm tắt 100% tiếng Việt bằng Gemini 3.8 Flash.
> Báo cáo sẽ tự động cập nhật vào mỗi 06:00 sáng hàng ngày tại tệp này!

---

### Hướng dẫn sử dụng:
1. Vào tab **Actions** -> Chọn **TopGit Radar Auto-Scan** -> Bấm **Run workflow** để chạy quét ngay.
2. Sau khi quét xong (khoảng 1-2 phút), quay lại trang chủ của Repository này để đọc danh sách báo cáo chi tiết.
3. Nếu muốn xem dạng Web App: Vào **Settings** -> **Pages** -> Chọn **Branch: main** -> Bấm **Save**.
